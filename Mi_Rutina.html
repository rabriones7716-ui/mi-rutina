📲 Instalar en Android

Para instalarla como app real (pantalla completa, ícono propio y caché sin internet) hay que abrirla desde una dirección web (https):

  1. Sube esta carpeta a un hosting gratis (Netlify Drop o GitHub Pages — ver LÉEME.txt).
  2. Abre esa URL en Chrome del teléfono.
  3. Menú ⋮ → Instalar app · se abre como app y funciona offline.

Atajo rápido (sin hosting): abre el archivo en Chrome → ⋮ → "Agregar a pantalla de inicio". Crea un acceso directo (puede no guardar los datos de forma permanente).
